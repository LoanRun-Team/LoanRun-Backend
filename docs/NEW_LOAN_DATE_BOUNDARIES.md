# 신규 대출 날짜 경계 (#205)

- 변동금리 등록일의 최초 금리 이력은 등록 기본값이다. 등록일에 첫 수동 금리 변경을 허용하며, 같은 날 두 번째 변경은 409 `RATE_HISTORY_CONFLICT`다. 최신 잔액 보정일보다 과거 금리는 허용하지 않는다.
- 등록 전 납부는 대출 `start_date` 이후, 오늘 이하의 날짜에만 기록한다. `principal_amount`, `extra_amount`, `interest_amount`, `fee_amount` 네 항목을 모두 제공하고 합계가 `amount`와 일치해야 한다. 이 과거 이력에는 등록 당시 이미 반영된 원금이므로 현재 잔액을 다시 차감하지 않는다. 과거 정기 납부는 저장된 회차가 없으므로 `due_item_id`를 보내지 않는다. 적립금 사용은 등록 당시 잔액과 중복되므로 허용하지 않는다. 응답의 `editable=false`다.
- 등록 전 적립은 실제 `saved_at` 월에 기록한다. 등록 시 입력한 현재 적립금에는 이미 반영된 금액이므로 현재 자산에 더하지 않는다. 응답의 `editable=false`다. 등록 이후이면서 최신 보정일 이전인 기록은 기존 정합성 제한을 유지한다.
- 다음 납부일에 적용될 계획이 아직 시작되지 않은 동안의 납부는 그 계획 진행률에 포함하지 않는다. 해당 월에 실제 납부가 있고 계획 시작 원금과 일정이 확인되면 `planned_progress_pct`와 `actual_progress_pct`는 구조적 0%다. `track.status`는 관측 완료 및 적용 전 목표가 없으므로 null을 유지한다.

등록 이전 월의 납부/적립 이력은 조회와 관측의 실제 원천이다. 등록 이전의 계약 원금·당시 의무 회차는 저장되지 않았으므로 과거 원금 잔액/연체 상태를 추정하지 않는다.
